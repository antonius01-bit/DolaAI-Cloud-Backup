# 📖 PANDUAN SINKRONISASI KE 3 CLOUD
> Google Drive + Obsidian Sync + GitHub

## ✅ Cara Upload ke Google Drive
1. Buka: drive.google.com
2. Klik "Baru" → "Unggah Folder"
3. Pilih folder: `DolaAI-Complete-Cloud-Backup`
4. Tunggu selesai → ✅ Data aman

## ✅ Cara Aktifkan Obsidian Sync
1. Buka Obsidian → "Buka Vault" → Pilih folder ini
2. Pengaturan → Layanan → Masuk akun Obsidian
3. Aktifkan "Sinkronisasi Obsidian"
4. ✅ Otomatis sinkron semua perubahan

## ✅ Cara Upload ke GitHub
1. Buka: github.com → Login/Daftar
2. Klik "New Repository" → Nama: `DolaAI-Cloud-Backup` → Pilih "Pribadi"
3. Di halaman repo → klik "uploading an existing file"
4. Tarik-taruh SEMUA file ke halaman
5. Klik "Commit changes"
6. ✅ Semua versi tersimpan selamanya

## 🔄 Cara Kerja Sistem Hybrid
- ✅ Saat ONLINE → otomatis sinkron ke 3 tempat
- ✅ Saat OFFLINE → baca langsung dari folder komputer
- ✅ Saat kembali ONLINE → semua perubahan naik otomatis
- ✅ Hapus dari Desktop SETELAH yakin semua upload BERHASIL
